Это не просто очередной линтер или анализатор кода. Это целая экосистема для автоматизированного рефакторинга исходного кода, созданная, чтобы помочь разработчикам эффективно бороться с техническим долгом и поддерживать кодовую базу в актуальном состоянии.
Задачи:
1. Масштабные миграции и обновления версий

  • перевести проект с Java 8 на Java 11 или 17
  • мигрировать с устаревшей версии Spring на более новую
2. Автоматическое исправление уязвимостей (CVE)
3. Поддержание стилевой консистентности и устранение техдолга.

OpenRewrite может выступать в роли "полицейского стиля", автоматически приводя код к единому формату, переименовывая переменные, изменяя структуры, удаляя неиспользуемый код или применяя паттерны, которые вы считаете лучшими практиками. Это значительно снижает время на код-ревью.
4. Расширяемость: Создавайте свои рецепты
Вы можете создавать свои собственные рецепты, используя Java (или Kotlin/Groovy) для описания логики преобразований.
