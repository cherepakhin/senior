Документация

Сам инструмент OpenCode — бесплатный, с открытым исходным кодом. Его можно установить и начать использовать без каких-либо платежей. Плата возникает не за сам агент, а за доступ к языковым моделям (провайдерам), которые OpenCode использует для работы.

Установка

curl -fsSL https://opencode.ai/install | bash

Промпты:
  1. generate project spring mvc with maven
  2. use themleaf
  3. use java 11
  4. convert to spring boot
  5. create run script
  6. commit
  7. change theme gmail
  8. примени стиль material design
  9. возьми цветовую схему с сайта v.perm.ru
