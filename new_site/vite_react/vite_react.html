Проект на GitHub: https://github.com/cherepakhin/vite_app Vite — это инструмент для сборки фронтенд-проектов из фреймворка Vue.js.

Подготовка к работе.

После клонирования проекта установить NVM (version v20.19.0): 
nvm use v20.19.0
yarn

Запуск проекта в dev режиме.

yarn dev
Открыть в браузере: http://localhost:5173/

Размещение на сайте с apache2.

Выполнить: 
yarn build
После этого, содержимое папки dist нужно скопировать в /var/www/main/vite_app (/var/www/main/ - это корень моего сайта apache2).
Результат https://v.perm.ru/vite_app/
