JBang это инструмент для запуска Java кода из консоли без установки дополнительных зависимостей, а также без maven/gradle.
Простой пример Jbang
Для установки Camel в JBang нужно выполнить команду:
jbang app install camel@apache/camel
Camel route тоже можно запускать подобным образом.
Примеры https://github.com/apache/camel-jbang-examples

Кроме того, Camel предоставляет Kamelet https://camel.apache.org/camel-kamelets/4.22.x/development.html
Kamelet это запуск маршрута прямо из yaml файла: https://github.com/apache/camel-kamelets-examples
