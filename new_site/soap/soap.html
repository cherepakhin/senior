WSDL
WSDL - Web Services Description Language. Это стандарт, который описывает веб-службы с помощью XML. По сути, это «паспорт» сервиса, который чётко фиксирует его интерфейс: какие методы доступны, какие параметры они принимают, какой формат ответа ожидается и где находится сам сервис.
Получить файл WSDL
http http://localhost:8080/ws/countries.wsdl
или 
http http://localhost:8080/ws/countries.wsdl > test1_result.xml
Результат:
test1_result.xml
<?xml version="1.0" encoding="UTF-8" standalone="no"?><wsdl:definitions xmlns:wsdl="http://schemas.xmlsoap.org/wsdl/" xmlns:sch="http://spring.io/guides/gs-producing-web-service" xmlns:soap="http://schemas.xmlsoap.org/wsdl/soap/" xmlns:tns="http://spring.io/guides/gs-producing-web-service" targetNamespace="http://spring.io/guides/gs-producing-web-service">
    <wsdl:types>
        <xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema" elementFormDefault="qualified" targetNamespace="http://spring.io/guides/gs-producing-web-service">

            <xs:element name="getCountryRequest">
                <xs:complexType>
                    <xs:sequence>
                        <xs:element name="name" type="xs:string"/>
                    </xs:sequence>
                </xs:complexType>
            </xs:element>

            <xs:element name="getCountryResponse">
                <xs:complexType>
                    <xs:sequence>
                        <xs:element name="country" type="tns:country"/>
                    </xs:sequence>
                </xs:complexType>
            </xs:element>

            <xs:complexType name="country">
                <xs:sequence>
                    <xs:element name="name" type="xs:string"/>
                    <xs:element name="population" type="xs:int"/>
                    <xs:element name="capital" type="xs:string"/>
                    <xs:element name="currency" type="tns:currency"/>
                </xs:sequence>
            </xs:complexType>

            <xs:simpleType name="currency">
                <xs:restriction base="xs:string">
                    <xs:enumeration value="GBP"/>
                    <xs:enumeration value="EUR"/>
                    <xs:enumeration value="PLN"/>
                </xs:restriction>
            </xs:simpleType>
        </xs:schema>
    </wsdl:types>
    <wsdl:message name="getCountryResponse">
        <wsdl:part element="tns:getCountryResponse" name="getCountryResponse">
        </wsdl:part>
    </wsdl:message>

            <soap:operation soapAction=""/>
            <wsdl:input name="getCountryRequest">
                <soap:body use="literal"/>
            </wsdl:input>
            <wsdl:output name="getCountryResponse">
                <soap:body use="literal"/>
            </wsdl:output>
        </wsdl:operation>
    </wsdl:binding>
    <wsdl:service name="CountriesPortService">
        <wsdl:port binding="tns:CountriesPortSoap11" name="CountriesPortSoap11">

Примеры использования WSDL (для проекта из примера выше)

Параметры запроса request.xml(получить информацию об Испании):
<soapenv:Envelope xmlns:soapenv="http://schemas.xmlsoap.org/soap/envelope/"
                  xmlns:gs="http://spring.io/guides/gs-producing-web-service">
   <soapenv:Header/>
   <soapenv:Body>
      <gs:getCountryRequest>
         <gs:name>Spain</gs:name>
      </gs:getCountryRequest>
   </soapenv:Body>
</soapenv:Envelope>
Выполнение запроса с параметром request.xml к SOAP сервису http://localhost:8080/ws: 
curl --header "content-type: text/xml" -d @request.xml http://localhost:8080/ws
Или с форматированием результата:
curl --header "content-type: text/xml" -d @request.xml http://localhost:8080/ws  | xmllint --format - | source-highlight -s xml -f esc

Tydy
Tidy - программа для форматирования HTML, XML и других форматов кода. 
curl --header "content-type: text/xml" -d @request.xml http://localhost:8080/ws  | tidy -xml -iq

Xmlstarlet
Xmlstarlet - программа для форматирования XML кода. 
curl --header "content-type: text/xml" -d @request.xml http://localhost:8080/ws  | xmlstarlet fo

Подсвечивание синтаксиса XML
С форматированием (xmllint) и выделение цветом (source-highlight): 
curl --header "content-type: text/xml" -d @request.xml http://localhost:8080/ws  | xmllint --format - | source-highlight -s xml -f esc
