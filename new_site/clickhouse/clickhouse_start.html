Установка: Установка и использование ClickHouse на Linux
How to Install and Connect to ClickHouse Using Java

sudo apt install apt-transport-https ca-certificates dirmngr
sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv 8919F6BD2B48D754
sudo echo "deb https://packages.clickhouse.com/deb stable main" > /etc/apt/sources.list.d/clickhouse.list
sudo apt update
sudo apt install clickhouse-server clickhouse-client
Конфигурация сервера : /etc/clickhouse-server/config.xml
После установки clickhouse мы можем подключиться к серверу без ввода логина и пароля под пользователем default. Для этого в консоли ввести команду: 
clickhouse-client
или с удаленной машины: 
clickhouse-client -h v
