Shop Application with AI OpenCode

Приложение Spring Boot shop с товарами и категориями товаров.

Git проекта: https://gitverse.ru/cherepakhin/opencode_shop

Используемые технологии

  • Java 11
  • Spring Boot 2.7.18
  • Spring Data JPA persistence
  • H2 file-based database (data persists across restarts)
  • Thymeleaf view technology
  • Maven build tool

Начало

Установка OpenCode: https://opencode.ai/docs/ru.

opencode

Требования

  • Домашняя страница магазина со сводкой запасов
  • Product CRUD операции:
    • Список всех товаров (с категорией)
    • Просмотр товара с деталями
    • Создание, редактирование, удаление товаров
    • Назначение категории товару
  • Категория CRUD операции:
    • Просмотр списка категорий
    • Просмотр подробной информации о категории и ее продуктах
    • Создание, редактирование, удаление категории
  • Для хранения данных используется H2 database file (./data/shopdb.mv.db)
  • Загрузка стартовых данных при первом запуске.
  • Запуск на web сервере /shop

Сборка и запуск

Сборка
# Build the project
mvn clean package
Запуск
run.sh:
mvn spring-boot:run

Доступ по адресу: http://localhost:8089/shop

Приложение сделано для запуска с URL /shop

Консоль H2 по адресу: http://127.0.0.1:8089/shop/h2-console/ (пользователь sa, без пароля).

Endpoints

Products

MethodPathDescription
GET/productsList all products
GET/products/newCreate product form
POST/productsSave new product
GET/products/{id}Product details
GET/products/{id}/editEdit product form
POST/products/{id}Update product
POST/products/{id}/deleteDelete product

Deployment

Смотри DEPLOY.md for instructions on deploying to https://v.perm.ru/shop (systemd service + Apache reverse proxy).

or

scp target/shop-1.0-SNAPSHOT.jar vasi@v:/home/vasi/temp/shop.jar

Конфигурация Apache2

Добавить в /etc/apache2/sites-enabled/000-default-le-ssl.conf:

<VirtualHost>
....
	ProxyPass        /shop http://localhost:8092/shop
	ProxyPassReverse /shop http://localhost:8092/shop
....
</VirtualHost>

Открыть в браузере https://v.perm.ru/shop.

Linux service

/etc/systemd/system/shop.service:

[Unit]
Description=ShopHub Spring Boot Application
Documentation=https://v.perm.ru/shop
After=network.target

[Service]
Type=simple
User=shop
WorkingDirectory=/home/vasi/temp/shop
ExecStart=/usr/bin/java -jar -Xms256m -Xmx512m /home/vasi/temp/shop/shop.jar
SuccessExitStatus=143
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal
Environment=PORT=8092

[Install]
WantedBy=multi-user.target
