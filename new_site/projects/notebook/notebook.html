https://github.com/cherepakhin/notebook.

CRUD приложение использует spring-boot-starter-web и template Thymeleaf и базу данных MySQL. Данные хранятся в базе MySQL, обмен проходит с помощью query-запросов и организует фильтрацию, сортировку по значениям, регулируемую с помощью элементов управления в пользовательском интерфейсе.

  • Использован template Thymeleaf (очень симпатичный Bootstrap интерфейс с доработанным css).
  • Постраничная навигация.
  • Редактирование записи.
  • Переход по страницам.


Сборка и запуск приложения

Используется Java 8.

export JAVA_HOME=/usr/lib/jvm/java-1.8.0-openjdk-amd64

Сборка:

./mvnw clean package

Запуск:

./run_jar.sh

/usr/lib/jvm/java-1.8.0-openjdk-amd64/bin/java -jar target/Notebook-0.0.1-SNAPSHOT.jar

Открыть http://127.0.0.1:8990/


Размещение на сервере Linux

Создать файл /etc/systemd/system/notebook.service:

[Unit]
Description=notebook
Wants=network-online.target
After=network-online.target
[Service]
Type=simple
User=vasi
Group=vasi
ExecReload=/bin/kill -HUP
ExecStart=/usr/lib/jvm/java-1.8.0-openjdk-amd64/bin/java -jar target/notebook-0.0.1.jar
SyslogIdentifier=notebook
StandardOutput=file:/var/log/notebook.stdout.log
StandardError=file:/var/log/notebook.stderr.log
Restart=always
[Install]
WantedBy=multi-user.target

Перечитать сервисы:

systemctl daemon-reload

И запустить:

systemctl start notebook
