Попробовал в __Visual Studio Code__ на проекте __hr_admin__.
Работает через окно управления "SourceCraft Code Assistant Agent".

Использован режим "Code".

Открыть файл для редактирования и в окне "SourceCraft Code Assistant Agent" вводить запросы. 
Изменения будут вноситься в файл с кодом.
