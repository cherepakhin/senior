Spring Mobile ( __НЕ Spring BOOT__ ) — это отдельный модуль (проект) и объявлен __УСТАРЕВШИМ__ в экосистеме Spring, который как раз добавлял 
функционал для адаптации веб-приложений под разные устройства (мобильные, планшеты и т.п.). 
Он умел определять тип устройства по запросу (анализируя User-Agent), и на основе этого можно 
было отдавать разные шаблоны представлений (views), оптимизировать загрузку ресурсов под 
медленные мобильные сети, использовать разные CSS-фреймворки. 

__Важное предупреждение:__ сейчас проект Spring Mobile объявлен __устаревшим (deprecated)__ и больше не поддерживается. 
В современных проектах его не используют. Вместо этого рекомендуют:
- Стратегии адаптивной вёрстки с использованием CSS-фреймворков (см. мой Tailwind.md).
- Встроенные возможности Spring Web (например, анализировать запрос в контроллере через параметр 
    типа __Device__ см. [https://github.com/cherepakhin/device-resolution](https://github.com/cherepakhin/device-resolution));
- Сторонние библиотеки вроде UADetector;
