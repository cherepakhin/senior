Spring Mobile

Это отдельный модуль (проект) и объявлен УСТАРЕВШИМ в экосистеме Spring, который как раз добавлЯЛ функционал для адаптации веб-приложений под разные устройства (мобильные, планшеты и т.п.). Он умел определять тип устройства по запросу (анализируя User-Agent), и на основе этого можно было отдавать разные шаблоны представлений (views), оптимизировать загрузку ресурсов под медленные мобильные сети, использовать разные CSS-фреймворки. Важное предупреждение: сейчас проект Spring Mobile объявлен УСТАРЕВШИМ(deprecated) и больше не поддерживается. В современных проектах его не используют. Вместо этого рекомендуют Spring Device (см.ниже).

Spring Device

https://github.com/cherepakhin/device-resolution
Используются встроенные возможности Spring Web (например, анализировать запрос в контроллере через параметр типа Device).
